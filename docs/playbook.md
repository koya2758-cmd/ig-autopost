# Instagram バズ設計プレイブック（2026年アルゴリズム対応）

最終更新: 2026-10-06 / 出典は末尾

## 最重要の前提
2026年の最重要ランキングシグナルは **Sends per Reach（DMシェア率）**。Meta公式が「いいね率より重みが大きい」と言及。
→ 投稿設計の中心は「いいね」ではなく **保存 と DMシェア**。

## スライド構成

- **枚数は8〜10枚**。4〜7枚は最もエンゲージメントが落ちるゾーン
  - カルーセル平均エンゲージメント率 0.55%（リール0.52%、単一画像0.30%）
  - 10枚構成で2.07%の実績。単一画像比で保存70%増・リーチ55%増
- 構成は **問題提起 → 原因 → 解決策 → 実践手順 → まとめ** の5ステップで流す
- 9枚目に「要点まとめ」を1画面で配置（ここが保存トリガー）
- チェックリスト形式はシェア率が特に高い

## 1枚目（表紙）
フィードで見えるのはここだけ。必ず次のどれかを入れる。

- 数字（「3つ」「9割」「5歳まで」）
- 質問形（「ぶどう、丸ごとあげてない？」）
- 意外な事実（常識を否定する）

悪い例：「子どもの安全について」/ 良い例：「3歳の口は4cm。この大きさ、知ってた？」

## キャプション

1. **冒頭2行が全て**。フィードで表示されるのは1〜2行のみ。数字・具体的ベネフィット・ティーザーを置く
2. **1投稿1アクション**。CTAを複数置くと逆効果。教育系は「保存」に統一
3. **使用シーンを明示して保存を促す**。「次に〇〇する時のために保存して」という形式が効く
4. スライドは視覚的理解、キャプションは補足説明と役割分担する
5. 末尾にDMシェア誘導を1行。「〇〇で悩んでる友達に送ってあげて」が直接効く

### キャプションの型
```
<フック1行：数字か質問>

<共感2行：読者の状況を言語化>

<本編：絵文字番号つき箇条書き 5〜7項目>

<保存CTA 1行：使用シーンを明示>
<DMシェアCTA 1行>

出典
・<一次情報を列挙>

<ハッシュタグ3〜8個>
```

## ハッシュタグ（重要な方針転換）

- **3〜8個に厳選**。30個の時代は終わり、現在は逆効果になるリスクがある
- Meta公式見解は「少数の関連性の高いハッシュタグを使用してください」
- 適切に使うと未使用比で平均30〜50%リーチ増
- 構成の目安：**ミドルタグ3個＋スモールタグ2〜3個＋ブランドタグ1個**
  - ビッグタグ（100万件超）は投稿直後に埋もれるため中心に据えない
  - ミドルタグ（1万〜100万件）が中核。上位表示が狙え長期的にリーチが続く
  - スモールタグ（1万件以下）は検索意図が明確でフォロー転換に近い

### 当アカウントの標準セット（例）
ミドル: #育児の悩み #幼児食 #子どもの事故防止
スモール: #1歳児ママと繋がりたい #2歳差育児 #誤飲防止
ブランド: #子育てパパの便利情報

投稿テーマに合わせて毎回入れ替える。使い回さない。

## 避けること
- ハッシュタグの大量羅列（#育児 #子育て など巨大タグを20個並べる旧手法）
- 1投稿に複数のCTA
- 表紙に抽象的なタイトル
- 4〜7枚の中途半端な枚数
